## 📖 معرفی پروژه (Overview)
**چی بپزم؟** یک سامانه هوشمند و مدرن برای پیشنهاد غذاهای سنتی و اصیل ایرانی بر اساس مواد اولیه موجود در یخچال و کابینت کاربر است. 

بزرگ‌ترین چالش پلتفرم‌های دستور پخت، سردرگمی کاربر هنگام نداشتن تمام مواد است. این موتور با منطق ریاضی **نظریه مجموعه‌ها (Set Operations)**، خروجی را به دو دسته شفاف تفکیک می‌کند:
1. **غذاهای آماده طبخ (۱۰۰٪ تطابق):** تمام مواد اولیه اصلی در خانه موجود است.
2. **غذاهای با کسری ۱ یا ۲ قلم:** مواردی که کاربر تنها به ۱ یا ۲ قلم ماده دیگر نیاز دارد، همراه با برچسب مشخص‌کننده کسری دقیق ماده برای تصمیم‌گیری یا خرید آسان.

---

## 🌟 قابلیت‌های برجسته (Key Features)
* **انتخاب همزمان مواد اولیه:** تفکیک در دسته‌بندی‌های پروتئین، غلات، صیفی‌جات و لبنیات/چاشنی‌ها.
* **دکمه‌های تست سریع (Presets):** تست آنی غذاهای پرطرفدار (املت، کوکو سیب‌زمینی، زرشک‌پلو، عدس‌پلو، کتلت).
* **کارت اختصاصی هر دستور پخت:** نمایش زمان آماده‌سازی، تعداد نفرات، درجه سختی، مقادیر دقیق مواد و مراحل پخت گام‌به‌گام.
* **پایگاه داده سبک و خودکفا:** پایگاه داده پایدار SQLite بدون نیاز به راه‌اندازی سرورهای سنگین دیتابیس.
* **معماری ماژولار و REST API پایتون:** قابلیت استفاده هم به صورت وب‌سایت مستقل و هم به عنوان میکروسرویس برای وردپرس، اپلیکیشن موبایل یا ربات تلگرام.
* **صفر وابستگی خارجی:** پیاده‌سازی بک‌اند با ماژول‌های استاندارد پایتون (بدون نیاز به `pip install`).

## 🚀 نحوه نصب و اجرای سریع (Quick Start)

### ۱. اجرای وب‌اپلیکیشن (آفلاین / بدون سرور)
کافیست فایل `index.html` را در هر مرورگری (Chrome, Edge, Firefox, Safari) باز کنید.

### ۲. اجرای وب‌سرور و REST API پایتون
این پروژه با کتابخانه‌های استاندارد پایتون نوشته شده و نیازی به نصب هیچ پکیجی ندارد:

```bash
# تست کنسولی عملکرد الگوریتم
python3 persian_recipe_engine.py test

# اجرای وب‌سرور لوکال
python3 persian_recipe_engine.py
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
> **http://127.0.0.1:8080**

## 🔌 مستندات اندپوینت‌های وب‌سرویس (API Endpoints)

| متد | مسیر (Route) | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/api/ingredients` | دریافت فهرست کامل مواد اولیه و دسته‌بندی‌ها |
| `POST` | `/api/suggest` | ارسال آرایه شناسه‌های مواد موجود و دریافت غذاهای منطبق و دارای کسری |
| `GET` | `/api/recipes` | فهرست کلیه دستورهای غذایی ثبت‌شده |
| `POST` | `/api/recipes` | افزودن یا ویرایش دستور غذایی جدید (پنل ادمین) |

### نمونه درخواست پیشنهاد غذا (POST /api/suggest):
```json
{
  "ingredients": ["egg", "tomato"]
}
```

### نمونه پاسخ (Response):
```json
{
  "success": true,
  "selected_count": 2,
  "full_matches": [
    {

      "servings": "۲ نفر",
      "difficulty": "خیلی آسان",
      "missing_count": 0
    }
  ],
  "partial_matches": [
    {
      "id": "kuku_sibzamini",

}
```
